# Claude через папку — OpenLinks 0.16

Расширение кладёт задания в папку на рабочем столе. Локальный обработчик запускает **Claude Code**, сохраняет ответ в TXT и возвращает его расширению. Claude Code может работать через подписку Claude Pro: отдельный API-ключ для этого режима не нужен. Лимиты подписки сохраняются.

**Без интернета Claude не генерирует ответы.** Установленный Claude Desktop сам не следит за папкой. Эту работу выполняет обработчик OpenLinks и отдельная командная программа Claude Code. При отсутствии сети, авторизации или доступного лимита задание остаётся в очереди, обработка приостанавливается до явного возобновления.

## Установка на Windows

Нужны обычный Chrome с установленным OpenLinks 0.16+, Python 3.12+ и Claude Code. Права администратора для моста не требуются. Все компоненты устанавливаются для текущего пользователя.

1. Установите Python с [python.org](https://www.python.org/downloads/windows/). Нужны `python.exe` и `pythonw.exe` из одной установки.
2. Установите Claude Code по [официальной инструкции](https://github.com/anthropics/claude-code#readme). На Windows доступна команда `winget install Anthropic.ClaudeCode`. Вход в приложение Claude Desktop не заменяет вход в Claude Code.
3. В `chrome://extensions` скопируйте ID установленного OpenLinks. Откройте PowerShell в папке распакованного архива и выполните:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\bridge\Install-Bridge.ps1 -ExtensionId "ID_РАСШИРЕНИЯ" -AutoStart
   ```

   Если программы не найдены автоматически, добавьте `-PythonPath "C:\полный\путь\python.exe" -ClaudePath "C:\полный\путь\claude.exe"`. `-Folder "C:\полный\путь\OpenLinks-Claude"` задаёт другую папку. `-AutoStart` запускает обработчик при входе в Windows; без этого флага его можно запускать ярлыком вручную.

4. На рабочем столе появится **OpenLinks-Claude**. После восстановления интернета откройте **Login Claude.cmd** и войдите в аккаунт с подпиской Pro. Команда входа — `claude auth login --claudeai`; она открывает браузер. Проверка — `claude auth status --text`. Не выбирайте API/Console для этого способа работы.
5. В OpenLinks откройте **Диалоги с поставщиками → Подключение Claude → Подключить Claude**. Разрешите Chrome связь с локальной программой. Подключение выполняется через Native Messaging; открытый сетевой порт не требуется.

Установщик оставляет обработку выключенной. После обновления расширения заново привяжите три вкладки и запустите мониторинг. На ПК, где компонент уже установлен, повторять установку Python и Claude Code не требуется.

## Настройка работы

Блоки в расширении идут в порядке настройки. Шаги ниже описывают обычный режим; для проверки без отправки используйте тестовый режим следующим разделом.

1. **Подключение Claude.** Подключите локальный обработчик, выберите модель из списка и нажмите **«Сохранить модель»**. По умолчанию используется **Haiku · экономный**. Также доступны **Sonnet · сбалансированный** и **Opus · сложные задачи**. Доступность определяется вашей подпиской.
2. **Товар и правила общения.** Заполните товар, прикрепите материалы, укажите правила, WeChat и язык. Нажмите **«Получить важную информацию»**, проверьте полученные факты и вопросы, при необходимости исправьте их и нажмите **«Согласовать версию»**. Согласование выполняете вы.
3. **Мониторинг площадок.** Привяжите открытые авторизованные вкладки 1688, Alibaba и Made-in-China и нажмите **«Начать мониторинг»**. При подключённом Claude и согласованном товаре ответы готовятся автоматически.
4. **Переписки и ответы.** По умолчанию галочка **«Отправлять ответы автоматически»** выключена: ответ появляется в редакторе, вы можете изменить текст и нажать **«Отправить»**. **«Сохранить черновик»** сохраняет его без отправки. Кнопка **«Подготовить ответ»** запрашивает отдельный ответ по выбранной переписке.
5. Для полной автоматизации включите **«Отправлять ответы автоматически»**. После выполненной настройки эта галочка также запускает мониторинг, если он остановлен. Снятие галочки сохраняет подготовку черновиков, но возвращает отправку к вашему подтверждению.

Локальный обработчик выполняет задания последовательно, в том числе при закрытом окне управления расширением. Chrome, компьютер и обработчик должны работать и иметь доступ к сети. Подписка Claude продолжает учитывать использование моделей; отсутствие API-ключа не означает отсутствие лимитов.

Перед применением и отправкой ответа расширение повторно проверяет получателя, документ, последнюю часть истории, товар и правила. Это относится и к ручной кнопке **«Отправить»**: отправляется проверенный вами текст при действующем согласовании товара и запущенном мониторинге. Устаревший ответ отклоняется. Ручной черновик в редакторе сайта, вложение в нём, неполная история, неизвестный автор, CAPTCHA и смена получателя останавливают отправку. При редактировании товара или правил требуется новое согласование; оно позволяет продолжить подготовку ответов, если мониторинг и Claude остаются включёнными.

Отправка использует общие с основной очередью лимиты: **1688 — 7 попыток за 20 минут, Alibaba — 3, Made-in-China — без заданного количественного лимита**. Учитывается попытка, даже если последующая подготовка завершилась ошибкой. Автоматический ответ ждёт освобождения лимита без новой генерации. При ручной отправке текст остаётся черновиком: после окончания паузы нужно снова нажать **«Отправить»**. Отложенной отправки без вашего действия в ручном режиме нет.

После нажатия отправки или при неопределённом результате повторная попытка для той же истории блокируется, в том числе после перезапуска. При неопределённом результате проверьте чат. Надпись «кнопка отправки нажата» не подтверждает доставку или прочтение. Три вкладки мониторинга остаются открытыми.

## Проверка одного цикла без отправки

После подключения Claude, привязки вкладок и согласования товара включите **«Тестовый режим — без отправки»**, затем нажмите **«Проверить первый цикл»**. Расширение прочитает настоящую переписку, создаст задание в папке, получит реальный ответ Claude и заполнит поле сообщения площадки. На отправку оно не нажимает. После заполнения появится **«Цикл выполнен — сообщение не отправлено»** с получателем, текстом и местным временем; дальнейшая обработка трёх площадок ждёт вашей команды.

**«Проверить следующий цикл»** очищает только собственный неизменённый предпросмотр и помечает предыдущий ответ обработанным в отдельном состоянии теста. Это позволяет перейти к следующему необработанному входящему сообщению в этой или другой переписке. Настоящая история не получает вымышленного исходящего сообщения, а новое сообщение продавца не создаётся. Пока подходящих входящих нет, новый ответ не создаётся.

Если текст в поле площадки был изменён вручную, он не удаляется автоматически. Неоднозначный получатель, устаревший контекст или другая ошибка останавливают цикл с причиной. При блокировке сначала проверьте чат и вручную уберите мешающий тестовый текст, затем выключите и снова включите режим. Автоматического повторного запроса к Claude после такой ошибки нет; неизвестная попытка настоящей отправки также не повторяется.

Кнопка ручной отправки в тесте меняется на **«Проверить без отправки»**. Тестовые черновики сохраняют свою отметку после редактирования и выхода из режима; для настоящей отправки нужно удалить такой черновик и создать новый ответ в обычном режиме. Тест не добавляет попытку в счётчики отправок площадок.

Остановка или изменение настроек сохраняет сведения о завершённом предпросмотре для проверки и очистки. После перезапуска Chrome тестовый режим остаётся включённым, но мониторинг и обработка Claude выключены, а вкладки нужно привязать заново. Действуйте по показанному состоянию; заблокированный цикл требует проверки чата и нового тестового сеанса.

Тестовый режим выключает автоотправку, ставит основную очередь первичных обращений на паузу и блокирует настоящую отправку расширением из обоих разделов. При выходе автоотправка не восстанавливается, основная очередь остаётся на паузе. Проверка использует обычный Claude Code по подписке Pro/Max: работа с папкой и отсутствие отправки поставщику не отменяют расход лимита Claude. Отдельного входа, API-ключа или другого формата TXT/JSON для теста не нужно. Согласование товара остаётся обязательным.

## Если Claude сейчас без интернета

Подготовленные задания сохраняются. После восстановления подключения:

1. Выполните вход через **Login Claude.cmd**, если ещё не входили в Claude Code.
2. Если обработчик не запущен, откройте **Start worker.lnk**.
3. В расширении нажмите **Возобновить обработку** или **Подключить Claude**. Возобновление снимает паузу сети, авторизации или лимита. Перед применением старого задания контекст будет проверен заново.

Программа не меняет сетевые настройки Claude Desktop и не обходит ограничения подписки. Если доступ запрещён сетевой политикой вашего компьютера, восстановите обычное разрешённое подключение к Claude. Сон компьютера и закрытый Chrome задерживают чтение чатов и применение ответов.

## Что находится в папке

### Режим Claude и расход контекста

Для автоматической очереди используется **Claude Code в фоновом режиме `--print`**, с входом по подписке Pro/Max. Окно Claude Desktop для работы очереди не требуется. В выпадающем списке модели выберите **Haiku** для коротких ответов, **Sonnet** для сложного сопоставления спецификаций или **Opus** для наиболее сложных заданий. Доступность моделей и расход лимитов зависят от подписки. Меньшая модель сама по себе не сокращает число токенов входящего текста.

Обработчик заменяет стандартный промпт программирования короткой инструкцией, отключает внешние инструменты и расширенное размышление. В регулярные ответы входят согласованные сведения о товаре, правила и прочитанная переписка. Исходные товарные документы повторно не прикладываются; дубли настроек и внутренние метаданные кеша исключаются. Содержание сообщений и вложений сохраняется. Один и тот же принятый контекст не запускает повторную генерацию при очередной проверке папки.

Claude возвращает результат по строгой JSON-схеме. Обработчик проверяет поля и берёт только содержимое ответа, без служебного резюме. Для диалога результат — обычный UTF-8 TXT с текстом ответа, без пояснений модели. Для извлечения товара результат содержит JSON с полями `keyPoints`, `questions`, `warnings`. Сопутствующий служебный JSON связывает результат с заданием и содержит доступные счётчики `usage` (`inputTokens`, `outputTokens`, `cacheReadInputTokens`, `cacheCreationInputTokens`). Это измерение расхода токенов, а не денежный счёт по подписке.

| Путь | Содержимое |
|---|---|
| `inbox/<ID>/prompt.txt` | Читаемое задание для Claude |
| `inbox/<ID>/job.json` | Идентификатор, версия контекста и параметры задания |
| `inbox/<ID>/image-*` | Изображения, необходимые для этого задания |
| `outbox/<ID>.txt` | Готовый текст ответа |
| `outbox/<ID>.json` | Ответ и служебные данные для проверки соответствия |
| `state/` | Статусы, блокировки и состояние обработчика |
| `logs/bridge.jsonl` | Время, этапы и причины остановок |

TXT предназначены для просмотра. Расширение принимает завершённый результат вместе с проверяемыми служебными данными, а не произвольный файл с текстом. Для исправления ответа используйте редактор черновика в разделе **«Переписки и ответы»**. Не редактируйте служебные JSON и блокировки во время работы.

Промпты, изображения и ответы содержат данные товара и переписки; они остаются в вашей папке и передаются Claude при обработке. API-ключи в задания не включаются. Обработчик не разрешает Claude выполнять команды, открывать Chrome или использовать MCP-инструменты. Он принимает только завершённый ответ модели; неполный поток не отправляется поставщику.

Очередь ограничена 500 заданиями и 512 МиБ. Подтверждённые задания старше 30 дней могут очищаться автоматически; незавершённые не удаляются для освобождения места. При заполнении освободите подтверждённые старые файлы после остановки обработчика или сохраните их отдельно.

## Остановка и диагностика

- **Отключить Claude** выключает связь с обработчиком и автоматическую отправку. Остановка мониторинга прекращает чтение и отправку из диалогов. Пауза отдельной переписки или **Взять разговор на себя** отключает её автоматическую обработку.
- Причины остановок отображаются в панели папки, журнале диалогов и `logs/bridge.jsonl`. При сетевой ошибке повтор запускается явным возобновлением. После потери процесса во время генерации неизвестный результат требует проверки; автоматического повторного запроса нет.
- Компонент установлен в `%LOCALAPPDATA%\OpenLinksClaude`; настройки — `config.json`. Не меняйте папку с незавершёнными заданиями. Для смены ID расширения сначала остановите старую установку.
- Для отключения моста выполните `powershell -NoProfile -ExecutionPolicy Bypass -File .\bridge\Uninstall-Bridge.ps1`. Удаляется регистрация Chrome и автозапуск; задания, отчёты и авторизация Claude сохраняются.

## Проверки разработчика

```sh
python3 -m unittest discover -s tests -p 'test_folder_bridge.py'
npm test
npm run check
CHROMIUM_PATH=/usr/bin/chromium python tests/dialog_send_browser_test.py
CHROMIUM_PATH=/usr/bin/chromium python tests/dialogs_ui_browser_test.py
```

Тесты используют временные папки, синтетические страницы и подставной CLI. Они не отправляют сообщения поставщикам и не расходуют лимит Claude. Работа модели по подписке проверяется только после самостоятельного входа пользователя и подключения к интернету.
