# Claude через папку — OpenLinks 0.14

Расширение кладёт задания в папку на рабочем столе. Локальный обработчик запускает **Claude Code**, сохраняет ответ в TXT и возвращает его расширению. Claude Code может работать через подписку Claude Pro: отдельный API-ключ для этого режима не нужен. Лимиты подписки сохраняются.

**Без интернета Claude не генерирует ответы.** Установленный Claude Desktop сам не следит за папкой. Эту работу выполняет обработчик OpenLinks и отдельная командная программа Claude Code. При отсутствии сети, авторизации или доступного лимита задание остаётся в очереди, обработка приостанавливается до явного возобновления.

## Установка на Windows

Нужны обычный Chrome с установленным OpenLinks 0.14+, Python 3.12+ и Claude Code. Права администратора для моста не требуются. Все компоненты устанавливаются для текущего пользователя.

1. Установите Python с [python.org](https://www.python.org/downloads/windows/). Нужны `python.exe` и `pythonw.exe` из одной установки.
2. Установите Claude Code по [официальной инструкции](https://github.com/anthropics/claude-code#readme). На Windows доступна команда `winget install Anthropic.ClaudeCode`. Вход в приложение Claude Desktop не заменяет вход в Claude Code.
3. В `chrome://extensions` скопируйте ID установленного OpenLinks. Откройте PowerShell в папке распакованного архива и выполните:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\bridge\Install-Bridge.ps1 -ExtensionId "ID_РАСШИРЕНИЯ" -AutoStart
   ```

   Если программы не найдены автоматически, добавьте `-PythonPath "C:\полный\путь\python.exe" -ClaudePath "C:\полный\путь\claude.exe"`. `-Folder "C:\полный\путь\OpenLinks-Claude"` задаёт другую папку. `-AutoStart` запускает обработчик при входе в Windows; без этого флага его можно запускать ярлыком вручную.

4. На рабочем столе появится **OpenLinks-Claude**. После восстановления интернета откройте **Login Claude.cmd** и войдите в аккаунт с подпиской Pro. Команда входа — `claude auth login --claudeai`; она открывает браузер. Проверка — `claude auth status --text`. Не выбирайте API/Console для этого способа работы.
5. В OpenLinks откройте **Диалоги с поставщиками → Claude через папку → Подключить папку**. Разрешите Chrome связь с локальной программой. Подключение выполняется через Native Messaging; открытый сетевой порт не требуется.

Установщик оставляет обработку выключенной. После обновления расширения заново привяжите три вкладки и запустите мониторинг. На ПК, где компонент уже установлен, повторять установку Python и Claude Code не требуется.

## Настройка работы

1. Заполните товар, прикрепите материалы, сохраните изменения и нажмите **Обработать через папку Claude**. Результат появится в полях товара; отредактируйте его и нажмите **Согласовать версию**. Согласование не выполняется автоматически.
2. Привяжите открытые авторизованные вкладки 1688, Alibaba и Made-in-China. Включите чтение новых диалогов и запустите мониторинг.
3. Для первой проверки выберите переписку и нажмите **Ответ через папку Claude**. Ответ появится как черновик. ИИ использует согласованный товар, правила, язык, WeChat и прочитанную историю этой переписки.
4. Для постоянной работы включите **Автоматически создавать задания по новым сообщениям** и сохраните настройки. Обработчик выполняет задания последовательно. Он продолжает работать без открытого окна настроек; Chrome и компьютер должны работать и иметь доступ к сети.
5. Отдельный переключатель **Отправлять полученные ответы поставщикам автоматически** разрешает отправку. По умолчанию он выключен. До его включения ответы остаются черновиками. Во время разработки сообщения реальным поставщикам не отправлялись.

Перед применением ответа расширение повторно проверяет получателя, документ, последнюю часть истории, товар и правила. Устаревший ответ отклоняется. Ручной черновик, вложение в редакторе, неполная история, неизвестный автор, CAPTCHA и смена получателя останавливают отправку. Редактирование товара, правил или черновика в интерфейсе приостанавливает обработку. После сохранения и согласования изменений включите нужные режимы заново.

Отправка использует общие с основной очередью лимиты: 1688 — 7 попыток за 20 минут, Alibaba — 3, Made-in-China — без заданного количественного лимита. Учитывается попытка, даже если последующая подготовка завершилась ошибкой. Неопределённый результат нажатия не повторяется автоматически. Надпись «кнопка отправки нажата» не означает подтверждение доставки. Три вкладки мониторинга остаются открытыми.

## Если Claude сейчас без интернета

Подготовленные задания сохраняются. После восстановления подключения:

1. Выполните вход через **Login Claude.cmd**, если ещё не входили в Claude Code.
2. Если обработчик не запущен, откройте **Start worker.lnk**.
3. В расширении нажмите **Возобновить обработку** или **Подключить папку**. Возобновление снимает паузу сети, авторизации или лимита. Перед применением старого задания контекст будет проверен заново.

Программа не меняет сетевые настройки Claude Desktop и не обходит ограничения подписки. Если доступ запрещён сетевой политикой вашего компьютера, восстановите обычное разрешённое подключение к Claude. Сон компьютера и закрытый Chrome задерживают чтение чатов и применение ответов.

## Что находится в папке

### Режим Claude и расход контекста

Для автоматической очереди используется **Claude Code в фоновом режиме `--print`**, с входом по подписке Pro/Max. Окно Claude Desktop для работы очереди не требуется. Для коротких ответов можно выбрать `haiku` в настройках папки; для сложного сопоставления спецификаций — `sonnet`. Доступность моделей и расход лимитов зависят от подписки. Меньшая модель сама по себе не сокращает число токенов входящего текста.

Обработчик заменяет стандартный промпт программирования короткой инструкцией, отключает внешние инструменты и расширенное размышление. В регулярные ответы входят согласованные сведения о товаре, правила и прочитанная переписка. Исходные товарные документы повторно не прикладываются; дубли настроек и внутренние метаданные кеша исключаются. Содержание сообщений и вложений сохраняется. Один и тот же принятый контекст не запускает повторную генерацию при очередной проверке папки.

Claude возвращает результат по строгой JSON-схеме. Обработчик проверяет поля и берёт только содержимое ответа, без служебного резюме. Для диалога результат — обычный UTF-8 TXT с текстом ответа, без пояснений модели. Для извлечения товара результат содержит JSON с полями `keyPoints`, `questions`, `warnings`. Сопутствующий служебный JSON связывает результат с заданием и содержит доступные счётчики `usage` (`inputTokens`, `outputTokens`, `cacheReadInputTokens`, `cacheCreationInputTokens`). Это измерение расхода токенов, а не денежный счёт по подписке.

| Путь | Содержимое |
|---|---|
| `inbox/<ID>/prompt.txt` | Читаемое задание для Claude |
| `inbox/<ID>/job.json` | Идентификатор, версия контекста и параметры задания |
| `inbox/<ID>/image-*` | Изображения, необходимые для этого задания |
| `outbox/<ID>.txt` | Готовый текст ответа |
| `outbox/<ID>.json` | Ответ и служебные данные для проверки соответствия |
| `state/` | Статусы, блокировки и состояние обработчика |
| `logs/bridge.jsonl` | Время, этапы и причины остановок |

TXT предназначены для просмотра. Расширение принимает завершённый результат вместе с проверяемыми служебными данными, а не произвольный файл с текстом. Для ручной работы используйте отдельный режим **Промпт для Claude · TXT** в расширении. Не редактируйте служебные JSON и блокировки во время работы.

Промпты, изображения и ответы содержат данные товара и переписки; они остаются в вашей папке и передаются Claude при обработке. API-ключи в задания не включаются. Обработчик не разрешает Claude выполнять команды, открывать Chrome или использовать MCP-инструменты. Он принимает только завершённый ответ модели; неполный поток не отправляется поставщику.

Очередь ограничена 500 заданиями и 512 МиБ. Подтверждённые задания старше 30 дней могут очищаться автоматически; незавершённые не удаляются для освобождения места. При заполнении освободите подтверждённые старые файлы после остановки обработчика или сохраните их отдельно.

## Остановка и диагностика

- **Остановить обработку** выключает режим папки и автоматическую отправку. Пауза отдельной переписки или **Взять разговор на себя** отключает её автоматическую обработку.
- Причины остановок отображаются в панели папки, журнале диалогов и `logs/bridge.jsonl`. При сетевой ошибке повтор запускается явным возобновлением. После потери процесса во время генерации неизвестный результат требует проверки; автоматического повторного запроса нет.
- Компонент установлен в `%LOCALAPPDATA%\OpenLinksClaude`; настройки — `config.json`. Не меняйте папку с незавершёнными заданиями. Для смены ID расширения сначала остановите старую установку.
- Для отключения моста выполните `powershell -NoProfile -ExecutionPolicy Bypass -File .\bridge\Uninstall-Bridge.ps1`. Удаляется регистрация Chrome и автозапуск; задания, отчёты и авторизация Claude сохраняются.

## Проверки разработчика

```sh
python3 -m unittest discover -s tests -p 'test_folder_bridge.py'
npm test
npm run check
CHROMIUM_PATH=/usr/bin/chromium python tests/dialog_send_browser_test.py
CHROMIUM_PATH=/usr/bin/chromium python tests/dialogs_ui_browser_test.py
```

Тесты используют временные папки, синтетические страницы и подставной CLI. Они не отправляют сообщения поставщикам и не расходуют лимит Claude. Работа модели по подписке проверяется только после самостоятельного входа пользователя и подключения к интернету.
