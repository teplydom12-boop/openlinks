Адаптация к интерфейсу сайта
Без селекторов используется поиск по смысловым названиям. При неоднозначности очередь остановится. Укажите точные CSS-селекторы, если поиск не справляется. Каждый селектор должен находить ровно один видимый элемент; селектор успеха — новое подтверждение после отправки.
