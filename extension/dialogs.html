Мониторинг и ответы

Этот блок читает чаты и помогает подготовить ответы. По умолчанию ответы сохраняются черновиками. Отправка через папку Claude включается отдельно в её настройках. Очередь первичных обращений управляется отдельно.

Открытие переписки может снять отметку «непрочитано». При первом проходе могут открыться и прочитанные диалоги с превью. Сообщения не отправляются. Настройка применяется при запуске мониторинга; открываются только распознанные диалоги.

1. ТОВАР И ПРАВИЛА ОБЩЕНИЯ

Информация для ответов поставщикам

Не согласовано

Один активный товар применяется ко всем поставщикам в выбранных вкладках 1688, Alibaba и Made-in-China. Перед работой с другим товаром измените сведения и согласуйте их заново.

Файлы товара

Excel, PDF, DOCX, изображения и текст. До 8 файлов. Результат чтения каждого файла показан ниже; неподдерживаемый формат не считается прочитанным.

Файлов пока нет. Можно работать только с описанием.

Через API материалы передаются выбранному сервису. Промпт TXT формируется локально без ключа: перенесите его в Claude вручную, затем вставьте ответ обратно. Проверьте факты и вопросы перед согласованием. Исходные файлы хранятся в Chrome.

Сначала сохраните и согласуйте сведения о товаре.

После включения выбранные переписки и согласованные сведения передаются выбранному сервису во время мониторинга. Ответы остаются в этом окне; сообщения продавцам не отправляются. По умолчанию используется язык последнего сообщения продавца и естественный деловой стиль. Ручной режим TXT не требует API.

Claude через папку

Выключено

Расширение сохраняет задания в папку на компьютере. Локальный обработчик запускает Claude Code, возвращает результат в расширение и ведёт журнал. API-ключ в расширении не нужен.

Нужен Claude Code с входом в вашу подписку; одного установленного приложения Claude Desktop недостаточно. Для ответов Claude требуется интернет. Без соединения задания остаются в очереди.

Отправка выключена. Полученные ответы остаются черновиками для проверки.

Установка и настройка обработчика Claude Code ↗. Если локальный модуль не найден, установите его по инструкции и подключите папку повторно.

    Задание для ИИ и подключение

    Ключ не сохранён.

    Ключ и модель сохраняются отдельно для каждого сервиса. API оплачивается по условиям вашего API-аккаунта; подписка на чат Claude не заменяет API-ключ.
